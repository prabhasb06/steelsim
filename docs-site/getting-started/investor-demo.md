# 5. Investor demo

This guided presentation follows the capabilities currently implemented in SteelSim and ACAMIS. Allow time for the free hosted service to wake before the meeting, if applicable.

## Prepare

Use a desktop browser. Open the app, confirm the backend indicator is live, and select **Plant Builder → Demo**. Check that the ten-component TMT plant has loaded and passed topology validation. The optional AI review requires a provider key and working quota; the main demo runs without one.

## 1. Build and simulate

Show the process and utility connections in Plant Builder. Open **Simulation** and click **Run Simulation**. The control center displays live equipment status, process flow, power, cooling-water circulation, and simulation ticks. Select a component to inspect its readings. The values are generated by SteelSim's deterministic model; they are not physical sensor readings.

## 2. Show controlled recovery

Open **ACAMIS Intelligence** and select **Rolling mill** in Scenario Control. The simulated slowdown changes the mill readings and creates an incident labeled **Manual scenario**. Switch to **Autonomous Simulation**. ACAMIS schedules its approved low-risk simulated recovery; wait 12 running ticks and show the recovery event in the audit. The model gateway is optional for this procedure.

## 3. Show the approval gate

With the simulation still running, select **Furnace stability**. ACAMIS can apply simulated containment, then requires human verification for the final high-risk procedure. Show the intervention prompt and explain what an operator must approve. Apply the human intervention only if you want to complete that demo path.

## 4. Show automatic detection

Clear the scenario. In **Automatic Monitoring**, start **Demonstrate telemetry drift**. The demo changes simulated mill capacity; the backend detector watches the resulting throughput. After three running ticks below its threshold, it raises an incident labeled **Telemetry detector**. This is a defined rolling-throughput rule. Additional temperature, cooling, and power findings are shown as evidence for operator review; they do not trigger arbitrary automatic repairs.

## 5. Show the recorded run

Open **Operations History**. Select the run, play the frame replay, inspect its power trace and audit, and download the JSON incident report. **Restore as paused session** creates a separate session with the recorded plant and tick. Resume it explicitly if desired. Local SQLite storage retains recordings across process restarts; the current free hosted configuration does not provide durable storage across host replacement.

## Optional: request model advice

Connect your own compatible provider through **Advisory Model Gateway → Test & connect**, then click **Request model review**. This sends current simulated telemetry to the provider and displays its text response. The model has no direct authority to execute procedures. See [the model gateway reference](/task-3-acamis/model-gateway) for data-sharing and key-handling limits.

Describe the product as a simulation-only MVP with a deterministic response engine, automatic detection for specific measured deviations, and an optional advisory model. Real SCADA integration and physical control are future work.
